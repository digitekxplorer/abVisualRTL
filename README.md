# abVisualRTL
abVisualRTL is a Python-based Computer-Aided Design (CAD) tool used to visually design Finite State Machines (FSMs) and automatically generate synthesizable SystemVerilog and VHDL code.

It bridges the gap between whiteboard logic design and hardware implementation, allowing engineers to focus on state behavior rather than syntax errors.

Key Features:
•	Visual Editor: Drag-and-drop interface for creating states and transitions with smooth B-spline curves and grid snapping.
•	Multi-Language Support: Generates production-ready SystemVerilog and VHDL code.
•	Live Preview: A split-screen view updates the HDL code in real-time as you draw.
•	Logic Definition: Supports Moore actions (inside states), Mealy actions (on transitions), and complex transition logic with priority handling.
•	Modern Workflow: Includes Undo/Redo history, JSON file persistence, and PNG image export for documentation.
